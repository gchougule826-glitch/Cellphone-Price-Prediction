📱 Cellphone Price Prediction

A Machine Learning project developed to predict the price range of mobile phones based on their hardware and technical specifications. The project analyzes different cellphone features such as RAM, internal memory, battery capacity, camera quality, screen resolution, processor-related specifications, and connectivity features to determine the appropriate price category.

🔍 Project Highlights
Data Cleaning and Preprocessing
Exploratory Data Analysis (EDA)
Statistical Analysis and Visualization
Feature Selection and Engineering
Categorical Data Encoding
Correlation Analysis
Machine Learning Model Development
Model Evaluation and Comparison
Price Range Classification
Prediction of cellphone price categories
🛠️ Technologies Used

Python | Pandas | NumPy | Matplotlib | Seaborn | Scikit-learn | Jupyter Notebook

🎯 Objective

The main objective is to build a reliable Machine Learning model that can classify mobile phones into different price ranges based on their specifications, helping understand how hardware features influence cellphone pricing.

Short GitHub description:

Machine Learning project that predicts cellphone price ranges using mobile specifications such as RAM, battery, memory, camera, and display features.

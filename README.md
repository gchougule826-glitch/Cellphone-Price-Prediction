# Cellphone-Price-Prediction
A Machine Learning project that predicts cellphone price ranges based on features such as RAM, internal memory, battery capacity, camera specifications, screen size, and other device characteristics.
Technologies: Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

Key Features:

Data Cleaning & Preprocessing
Exploratory Data Analysis (EDA)
Feature Engineering
Classification Model Building
Model Evaluation
Price Range Prediction
